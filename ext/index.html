管理ポータル 機能拡張

ドコモ・バイクシェア管理ポータルの使い勝手を向上するブラウザ拡張です

1. ブックマークレットを登録する

最初に一度だけ、以下のブックマークレットをブラウザに登録してください。

登録方法

  1. 下の 「DBS拡張」ボタンをブックマークバーへドラッグ＆ドロップ してください。
  2. 管理ポータル（mg.docomo-cycle.jp）を開き、ログインします。
  3. 登録したブックマークをクリックすると、機能が追加されます。

【使い方】

  • 管理ポータルを開いているとき — その場で機能が追加されます。画面右下のパネルが青くなれば適用中です。
  • それ以外のページのとき — 管理ポータルが新しいタブで開きます。開いたタブでもう一度ブックマークを押してください。
  • 画面を再読込すると機能は外れます。その場合は再度ブックマークを押してください（右下パネルが赤に戻っていれば未適用です）。

2. 追加される機能

ブックマークレットを適用すると、管理ポータル上で以下の機能が使えるようになります。

  • バッテリーマップを開く — 左メニュー下部のボタンから、権限に応じたエリアのマップを表示
  • 一覧の並べ替え・絞り込み — 各列見出しの▲をクリックでソート、入力欄で絞り込み
  • 見出し行の固定 — 下にスクロールしても列名が常に表示される
  • 表示条件の折りたたみ — 「表示条件」「一括車両状態変更」「一括車両操作」を既定で閉じる
  • 「戻る」ボタンで1つ前の画面へ — お客様情報を見ているときも前の画面に戻れる
  • 一覧のリンクを別タブで開く — 絞り込み結果を残したまま個別画面を確認できる
  • 車両情報の表示件数を最大化（試験中）

3. より便利なChrome拡張版

ブックマークレット版よりさらに快適なChrome拡張版もあります。

ブックマークレット版との違い

  • 自動で適用 — ポータルを開くだけで自動適用。毎回ブックマークを押す必要なし
  • 外れない — 画面を再読込しても機能が維持される
  • サイドパネル表示 — 画面横にマップを並べて表示できる

導入手順

  1. Chrome のアドレス欄に chrome://extensions と入力して開く
  2. 右上の「デベロッパー モード」をオンにする
  3. 「パッケージ化されていない拡張機能を読み込む」を押す
  4. 配布された拡張機能のフォルダを選択する
  5. 管理ポータルを開き直す

※Chrome起動時に「デベロッパー モードの拡張機能」に関する確認が表示される場合があります。

4. 安全性について

  • 管理ポータルのデータを書き換えません。読み取りと画面表示の変更のみです。
  • 入力内容やログイン情報を外部へ送信しません。すべてブラウザ内で完結します。
  • 管理ポータル本体には一切手を加えていません。

5. 困ったとき

  • 機能が動かない — ログイン前に押していませんか？ ログイン後の画面で実行してください。
  • 管理ポータルが開かない — ポップアップブロックで新しいタブが止められている可能性があります。
  • マップが開かない — ポップアップブロックを確認し、許可してください。
  • サイドパネルが開かない（拡張版） — Chromeツールバー右上の拡張機能アイコン（パズルピース）から選択してください。
