管理ポータル 機能拡張

ドコモ・バイクシェア管理ポータルの使い勝手を向上するブラウザ拡張です

1. Chrome拡張を導入する

いちばんおすすめの導入方法です。一度インストールすれば、管理ポータルを開くだけで自動的に機能が使えます。

できること

  • 自動で適用 — ポータルを開くだけで自動適用。毎回ボタンを押す必要なし
  • 外れない — 画面を再読込しても機能が維持される
  • サイドパネル表示 — 画面横にマップを並べて表示できる

導入手順

  1. ⬇ dbs-portal-ext.zip をダウンロード
  2. ダウンロードした ZIP を 任意のフォルダに展開 します。
  3. Chrome のアドレス欄に chrome://extensions と入力して開きます。
  4. 右上の 「デベロッパー モード」をオン にします。
  5. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選択します。
  6. 読み込んだ拡張の「詳細」を開き、「ユーザー スクリプトを許可」をオンにします。 これをオンにしないと、以降の機能更新が自動で届きません（画面自体は動きます）。
  7. 管理ポータルを開き直すと、自動で機能が適用されます。

【更新方法】

機能の更新は自動で届きます。管理ポータルを開き直すだけで最新になります。 ZIPを取り直す必要はありません。

画面右上のパネルに、いま何で動いているかが小さく表示されます。

  • 配信版 — 最新の配信を受け取って動いています（正常）
  • 保存版 — 今回は取得できず、前回受け取った内容で動いています
  • 同梱版 — 配信を受け取れていません。 「ユーザー スクリプトを許可」がオフの可能性があります

なお、拡張そのものの入れ替えが必要になるのは、まれな場合（数か月に一度程度）だけです。 そのときは改めてご案内します。

2. 追加される機能

拡張機能（Chrome拡張版・ブックマークレット版）を適用すると、管理ポータル上で以下の機能が使えるようになります。

  • バッテリーマップを開く — 左メニュー下部のボタンから、権限に応じたエリアのマップを表示。QRコードでスマホからも同じ画面を開けます
  • 一覧の並べ替え・絞り込み — ポータルの各一覧とビーコン一覧で、列見出しからソート・絞り込みができます。車両情報の見出し全選択は、絞り込み中に表示されている行だけを対象にします
  • 見出し行の固定 — 下にスクロールしても列名が常に表示される
  • 見出し上の横スクロール — 表の上部から横へ移動でき、表本体と見出し列が同じ位置へ追随します。操作列の表示／非表示や画面差し替え後も表幅へ追随します
  • 表示条件の折りたたみ — 検索前に条件入力が必要な「ユーザ情報」を除き、「表示条件」「一括車両状態変更」「一括車両操作」を既定で閉じる
  • 「戻る」ボタンで1つ前の画面へ — お客様情報を見ているときも前の画面に戻れる
  • 一覧のリンクを別タブで開く — 絞り込み結果を残したまま個別画面を確認できる
  • 車両情報の表示件数を最大化 — ページャの選択肢のうち最大（500件）を自動選択
  • 読み込み中の表示 — 通信が0.25秒を超えると表に「読み込み中…」を重ねる。1秒を超えると経過秒数も表示（Chrome拡張版では自動で、ブックマークレット版ではクリック後に有効）
  • 通信エラー・ログイン切れのお知らせ — 失敗したことが分かる。自動での再送・再ログインは行いません
  • 操作列を既定で隠す — メンテナンス／AT管理／解錠／再配置／AT一体型車両操作の5列を隠し、表の横幅を詰める。「操作列を表示」で元に戻せます
  • 先頭列の固定 — 横スクロールしても車両識別番号が左に残る
  • 車両状態を色で確認 — ポータル標準の緑・茶・赤の状態色を、車両識別番号のセルだけに表示します
  • 車両詳細の問題申告を正しく表示 — 問題申告から車両番号を選んで開く詳細画面の表を、部位・重要度・事象が正しく対応した見やすい表に差し替えます。ヘッダ固定・フィルタ・並び替えも完備
  • エリア内ビーコン一覧 — 左メニューの「ビーコン情報」からポータル標準の画面遷移を使って開けます。標準の新規登録欄を上に残し、選択エリア内の割当済みビーコンを固定ヘッダ・7列フィルタ・並び替え付きで自動表示します。画面表示時に自動取得し、必要なときは「再取得」で更新できます。10桁のビーコン識別番号を押すと、ポータル標準の検索結果をコンパクトなモーダルで表示します。モーダル中は背景を操作できません。編集途中で閉じた場合は、標準の「取消」で編集状態を解除してから閉じます（更新・削除・保存・登録は自動実行しません）
  • ポート情報の一括操作（新機能） — 「ポート情報」画面に一括操作用の表を追加します。チェックボックスで複数ポートを選び、運用状態（運用中／運用中（貸出制限中）／一時駐輪用／一時休止中／停止中）や公開・非公開設定をまとめて変更できます。実行前に必ず対象と変更内容の確認画面が表示され、確定すると1件ずつ確認しながら順番に実行します（複数件を同時に書き換えることはありません）。各行には現在の公開設定も自動表示され、ポート識別番号から個別編集画面を別タブで開けます。見出しのチェックボックスで表示中の行を一括選択・解除できます。この機能のみ、ポータルのデータを実際に書き換えます（詳しくは「4. 安全性について」）
  • 元の画面表示に戻す — 画面右下のボタンで、拡張が追加した見た目・機能を一時的にすべて隠し、素のポータル画面を確認できます。ページを開き直すと自動的に拡張適用の表示へ戻ります
  • 文字を読みやすく — 表の見出しなどのコントラストをWCAG AA基準まで改善し、日本語フォント（BIZ UDPGothic）を指定
  • サイドバーを狭く — 280px → 180px。表に使える幅が広がります
  • エリア選択を覚える — 一度選んだエリアを次回から自動で適用します。適用したことは画面に表示され、1クリックで選び直せます（初回は自動適用しません）。対応エリア外のアカウントでは、バッテリーマップの起動ボタン自体を表示しません

3. ブックマークレット版（代替の導入方法）

Chrome拡張機能をインストールできない環境（会社のポリシーなど）向けの代替手段です。拡張機能のインストール権限なしに、ブラウザへ登録するだけで使えます。

登録方法

  1. 下の 「DBS拡張」ボタンをブックマークバーへドラッグ＆ドロップ してください。
  2. 管理ポータル（mg.docomo-cycle.jp）を開き、ログインします。
  3. 登録したブックマークをクリックすると、機能が追加されます。

【使い方】

  • 管理ポータルを開いているとき — その場で機能が追加されます。画面右下のパネルが青くなれば適用中です。
  • それ以外のページのとき — 管理ポータルが新しいタブで開きます。開いたタブでもう一度ブックマークを押してください。
  • 画面を再読込すると機能は外れます。その場合は再度ブックマークを押してください（右下パネルが赤に戻っていれば未適用です）。

4. 安全性について

  • ほとんどの機能は、管理ポータルのデータを書き換えません。読み取りと画面表示の変更のみです。
  • 例外は「ポート情報の一括操作」機能のみです。選択したポートの運用状態・公開設定を実際に書き換えます。 この機能は、①チェックボックスで対象ポートを選ぶ、②変更内容の確認画面が必ず表示される、③「実行」を押して確定する、 という手順を踏んだときだけ動きます。裏側での自動実行や、確認なしでの書き換えは一切行いません。 実行時は1件ずつ最新の内容を取得し直してから該当箇所だけを書き換えるため、他の項目（住所・シェア設定・ビーコン紐付け等）を 意図せず変更することもありません。
  • 入力内容やログイン情報を外部へ送信しません。すべてブラウザ内で完結します。
  • 管理ポータル本体には一切手を加えていません。

5. 困ったとき

  • 機能が動かない — ログイン前に押していませんか？ ログイン後の画面で実行してください。
  • 管理ポータルが開かない — ポップアップブロックで新しいタブが止められている可能性があります。
  • マップが開かない — ポップアップブロックを確認し、許可してください。
  • サイドパネルが開かない（拡張版） — Chromeツールバー右上の拡張機能アイコン（パズルピース）から選択してください。
