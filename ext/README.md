# ext フォルダ（案内ページ ＆ 最新版ブックマークレット配布領域）

このフォルダは、管理ポータル機能拡張（ブックマークレット版・Chrome拡張版）の案内ページおよび配信リソースです。

GitHub Pages により以下のURLで公開されます：
`https://dontsu87.github.io/DBSgetdata/ext/`

> **重要（契約）**  
> 上記のURLはブックマークレット（α版）のコード内に直接組み込まれています（ハードコード）。  
> フォルダ名（`ext/`）や公開URL・ファイル構成を後から変更しないでください。

---

## フォルダ構成

- `index.html`: 利用者・運用担当者向けの案内ページ
- `style.css`: 案内ページのスタイルシート（自己完結型）
- `guide.js`: 同一フォルダの `bookmarklet.txt` を読み込み、ブックマークバーへのドラッグ登録リンクやコピー機能を提供するスクリプト
- `README.md`: 本ファイル（開発・運用手順）

---

## リリース作業手順

ブックマークレットの最新版をリリースする際の作業手順です。

1. **ブックマークレットのビルド**
   `dbs-portal-ext` リポジトリにて、以下のビルドコマンドを実行します：
   ```bash
   node src/bookmarklet/build.mjs
   ```

2. **成果物の配置**
   生成された `dbs-portal-ext/dist/bookmarklet.txt` を、本フォルダ（`DBSgetdata/ext/bookmarklet.txt`）へコピーします。

3. **案内ページの修正（必要に応じて）**
   Chrome拡張の配布方法や導入手順に変更がある場合は、`index.html` の該当箇所を更新します。

4. **コミット ＆ push**
   変更内容を確認の上、Git コミットを行い GitHub へ push します。  
   ※ **push の実行判断は人間が行ってください。**
