# Docomo Bike Share 車両・バッテリー状態可視化ダッシュボード
(Docomo Bike Share Visualization Dashboard)

現場作業員および運行管理者の状況把握・バッテリー交換業務を支援するための、リアルタイム車両モニタリングダッシュボードです。

---

## 概要 (Overview)

本システムは、シェアサイクル事業における車両の稼働状況、バッテリー電圧低下車両、ポート内外の車両分布を地図上に可視化し、現場オペレーションおよび保守巡回業務の状況把握を支援するWebアプリケーションです。

---

## 設計方針と技術仕様 (Architecture & Specifications)

### 1. 現場端末における負荷軽減と応答性の重視 (Vanilla JS)
- **依存性の最小化**: 現場作業員が屋外で利用するモバイル端末・タブレットにおける省リソース動作（CPU・メモリ・バッテリー消費の抑制）を優先し、外部フレームワークやビルドパイプラインを介さず、Vanilla JavaScript (ES6+) および Leaflet.js を採用しています。
- **保守性の確保**: 外部依存を最小限に留めることで、長期運用におけるビルドツールの陳腐化リスクを排除し、シンプルな静的構成による高い可用性を維持しています。

### 2. ユーザー操作との整合性維持 (Pending Update 機構)
- **操作中の再描画抑止**: 作業員が地図のスクロール・拡大縮小や、ポート詳細ポップアップを閲覧・操作している間は、定期自動データ更新（2分周期）による画面再描画を一時保留（Pending）します。
- **サイレント適用**: ユーザーの操作完了（ポップアップ閉じ、マップ操作終了）を検知したタイミングで最新データをバックグラウンド適用し、現場での確認作業を中断させない設計としています。

### 3. 車種別電圧特性に応じた判定ロジック
- 車種（ママチャリ、シティ、マチガード等）ごとのバッテリー定格および電圧特性に応じた個別閾値判定を実装しています。
- エリア別、車両ステータス別、車種別の複合条件による動的フィルタリングを提供します。

### 4. PWA (Progressive Web Apps) 対応とモバイルUI最適化
- ホーム画面追加によるアプリ形式での起動に対応しています。
- iOS / Android それぞれのブラウザ特性に応じたビューポート制御およびLocalStorageを用いた設定状態の永続化（データ構造マイグレーション機能を含む）を備えています。

## 技術スタック (Tech Stack)

| **Data Delivery** | Cloudflare R2 / Worker (Edge Delivery) |
